# Folder Structure

## Top-Level Layout

```
src/
├── app/                  # Routes + co-located feature code
├── core/                 # Shared application logic
├── lib/                  # External integrations
└── components/           # Global reusable components
```

## `core/` Directory

Shared logic used across multiple features.

```
core/
├── constants/            # App-wide constants with barrel export
│   ├── index.ts
│   ├── pagination.ts
│   └── roles.ts
├── data/                 # Static data (dropdown options, configs)
├── factories/            # Builder/factory functions
├── fonts/                # Font loader configs (next/font)
├── hooks/                # Shared custom hooks
├── providers/            # Context providers + root-provider.tsx
├── stores/               # Zustand stores (non-persistent)
├── storage/              # Zustand stores with persist middleware
├── types/                # Shared TypeScript types/interfaces
└── utils/                # Pure utility functions
```

### Constants Barrel Export

```ts
// core/constants/pagination.ts
export const PAGINATION = { DEFAULT_PAGE: 1, DEFAULT_PAGE_SIZE: 10 } as const;

// core/constants/roles.ts
export const ROLES = { ADMIN: "admin", USER: "user" } as const;

// core/constants/index.ts
export * from "./pagination";
export * from "./roles";
```

Usage: `import { PAGINATION, ROLES } from "@/core/constants";`

## `lib/` Directory

External service integrations. Each file/folder wraps a third-party dependency.

```
lib/
├── api.ts                # Axios instance (axios.create + interceptors)
├── get-query-client.ts   # Shared QueryClient factory (getQueryClient)
├── auth.ts               # Auth config (e.g., next-auth)
├── db.ts                 # Database client
├── email.ts              # Email service client
└── ...
```

> `lib/api.ts` is the single Axios instance — all HTTP calls go through it.

## `components/` Directory

Global components shared across features.

```
components/
├── ui/                   # shadcn/Radix primitives (button, dialog, input)
└── custom/               # Composite reusable components (data-table, page-header)
```

- `ui/` — Generated by shadcn CLI, rarely edited manually
- `custom/` — Built from `ui/` primitives, used across multiple features

## Placement Rules

| Code type | Location | Example |
|-----------|----------|---------|
| Used by one feature only | Feature's `_components/`, `_hooks/`, etc. | `app/(dashboard)/projects/_hooks/use-projects.ts` |
| Used across multiple features | `core/` subdirectory | `core/hooks/use-debounce.ts` |
| Wraps an external service | `lib/` | `lib/api.ts` |
| UI primitive (shadcn) | `components/ui/` | `components/ui/button.tsx` |
| Composite global component | `components/custom/` | `components/custom/data-table.tsx` |
| App-wide constant | `core/constants/` | `core/constants/pagination.ts` |
| Zustand store (ephemeral) | `core/stores/` | `core/stores/use-sidebar-store.ts` |
| Zustand store (persisted) | `core/storage/` | `core/storage/use-theme-storage.ts` |
| Provider/context | `core/providers/` | `core/providers/query-provider.tsx` |
| Shared types | `core/types/` | `core/types/api.ts` |
| Page section (landing/marketing) | Feature's `_sections/` | `app/(marketing)/_sections/hero.tsx` |

## Key Conventions

- **Barrel exports** — Only in `core/` subdirectories (e.g., `core/constants/index.ts`), not in feature folders
- **Imports** — Use `@/` path alias pointing to `src/`
- **Route groups** — Use `(group)` folders in `app/` for layout grouping without affecting URL
- **Underscore prefix** — `_components/`, `_hooks/`, `_validations/`, `_sections/` are ignored by the Next.js router
